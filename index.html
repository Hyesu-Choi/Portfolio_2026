    • 하드코딩된 라우팅으로 2단계 메뉴·다시 듣기·오입력 재시도가 불가능하던 구조를 노드/엣지 그래프 모델과 실행 엔진(FlowRunner)으로 재설계했습니다.
    • 드래그·줌·연결선 위 단계 삽입이 가능한 노드 그래프 캔버스 편집기를 구현하고, 연속 드래그·입력을 한 단계로 묶는 50단계 Undo/Redo를 설계했습니다.
    • 사이클 탐지, 안내 멘트 없이 상담원 연결로 이어지는 경로 차단 등 그래프 검증기를 구현하고, 편집 중에는 서버 검증 API를 디바운스 호출하여 규칙을 서버 한 곳에서만 관리하도록 했습니다.
    • 멘트 저장 시 커밋 이후 비동기로 AWS Polly 음성 합성 → S3 → 전화 서버 배포로 이어지는 TTS 파이프라인을 구축했습니다.
    • 멘트 7종, 요일별 업무시간·공휴일(공공 API 동기화), 상담유형 트리 등 IVR 시나리오 관리 API 29개와 관리자 화면을 개발했습니다.
    • 상담원 클라이언트의 S3 · CloudFront · Route53 인프라와 GitHub Actions 기반 Dev/Prod 배포 파이프라인을 구축했습니다.

    핵심 성과

    • 기존 키 입력별 라우팅 결과와 동일함을 테스트로 검증하여 운영 흐름 변경 없이 그래프 구조로 안전하게 전환했습니다.

    • 실통화 테스트에서 "#" 입력이 무입력으로 처리되던 버그와 상담유형 순환 참조로 인한 무한루프를 원인 분석 후 해결했습니다.

    보건복지부 정책에 따라 분산된 대국민 금연 관련 홈페이지들을 통합하여 일원화된 관리 및 대국민 서비스 창구를 마련하는 대규모 공공 프로젝트입니다.

    주요 업무 및 구현

    • 유아 흡연 예방 교육 플랫폼의 프론트엔드 개발을 리딩하며 팀 내 코드 컨벤션 정의 및 개발 표준을 수립했습니다.
    • 사용자 및 관리자 플랫폼의 약 89페이지 퍼블리싱과 약 300건의 API 연동을 총괄하여 과업을 완수했습니다.
    • 첨부파일 업로드 및 멀티 이미지 첨부 모듈(대표 이미지 선택, Drag & Drop 순서 변경)을 구현하여 관리 기능을 고도화했습니다.
    • Toast UI Chart를 활용해 15종 이상의 운영 데이터 대시보드를 시각화하여 직관적인 데이터 확인이 가능하도록 구현했습니다.

    핵심 성과

    • 대규모 API 연동 환경에서 철저한 QA 대응 및 에러 수정을 통해 국가 프로젝트의 안정적인 릴리즈를 이끌었습니다.

    주요 업무 및 구현

    • 3개 플랫폼 전체 페이지의 퍼블리싱(100%) 및 약 260건의 API 연동을 수행하여 서비스 전 프로세스를 구축했습니다.
    • 디자인 시스템 도입을 위한 스타일 가이드를 작성하고, 감리 대응을 위한 기술 산출물을 문서화했습니다.
    • 서울 SSO, 서울시 공통 배너, 서울 통합 로그인 등 서울시 표준 외부 연계 API를 전담하여 안정적으로 연동했습니다.
    • FullCalendar 기반의 상담 예약/일정 관리 시스템과 Chart.js 기반의 맞춤형 재무 보고서 자동 생성 기능을 구현했습니다.

    핵심 성과

    • 웹 표준 및 접근성 가이드를 철저히 준수하여 한국정보접근성인증평가원으로부터 WA 인증마크를 획득했습니다.
    • 예약-상담-보고서로 이어지는 복합 사용자 플로우의 완성도를 높여 사업 운영에 필요한 전체 프로세스를 성공적으로 디지털화했습니다.
